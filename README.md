# IT Evaluator

เว็บแอปพลิเคชันสำหรับประเมินประสิทธิภาพและความพึงพอใจในการใช้งานระบบสารสนเทศ (IT) ของคณะสหเวชศาสตร์ มหาวิทยาลัยนเรศวร

## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้ช่วยให้ผู้ใช้งานประเมินได้ว่าระบบ IT ช่วยให้การทำงานสะดวก รวดเร็ว และมีประสิทธิภาพมากขึ้นเพียงใด พร้อมรวบรวมความคิดเห็นเพื่อนำไปปรับปรุงระบบในอนาคต

## ฟีเจอร์หลัก

- **แกลเลอรีหมวดหมู่ระบบ:** แสดง 6 หมวดหมู่งานพร้อมภาพประกอบและแอนิเมชันเปิดดูระบบย่อย
- **รายการระบบ IT:** แสดงรายชื่อระบบสารสนเทศทั้งหมด 21 ระบบ พร้อมรหัสระบบ
- **ประเมินประสิทธิภาพ Before & After:** เปรียบเทียบผลการปฏิบัติงานจริงก่อนและหลังใช้ระบบ 10 ข้อคำถาม
- **สรุปผลคะแนนและส่วนต่าง:** คำนวณค่าเฉลี่ยและแสดงผลต่างคะแนนทันที
- **ประเมินความพึงพอใจและข้อเสนอแนะ:** วัดความพึงพอใจ 5 มิติ พร้อมช่องกรอกข้อเสนอแนะ
- **Admin Dashboard & Reporting:** แดชบอร์ดวิเคราะห์สถิติ, กราฟเปรียบเทียบ, ตารางรายระบบ, ส่งออก HTML/PDF และรองรับการนำเข้าไฟล์ JSON

## โครงสร้างโปรเจกต์ (New Modular Architecture)

## วิธีเปิดใช้งาน

1. เปิดโฟลเดอร์ `evaluator`
2. **สำหรับผู้ทำแบบประเมิน:** เปิดไฟล์ `frontend/user/index.html` ผ่านเว็บเบราว์เซอร์
3. **สำหรับผู้ดูแลระบบ:** เปิดไฟล์ `frontend/admin/dashboard.html` หรือ `frontend/admin/login.html`
4. หรือเปิดผ่านส่วนขยาย Live Server บน Visual Studio Code
