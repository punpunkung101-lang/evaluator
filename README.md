# IT Evaluator

เว็บแอปพลิเคชันสำหรับประเมินประสิทธิภาพและความพึงพอใจในการใช้งานระบบสารสนเทศ (IT) ของคณะสหเวชศาสตร์ มหาวิทยาลัยนเรศวร

## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้ช่วยให้ผู้ใช้งานประเมินได้ว่าระบบ IT ช่วยให้การทำงานสะดวก รวดเร็ว และมีประสิทธิภาพมากขึ้นเพียงใด พร้อมรวบรวมความคิดเห็นเพื่อนำไปปรับปรุงระบบในอนาคต

## ฟีเจอร์หลัก

- แสดงหมวดหมู่และรายการระบบ IT ที่ต้องการประเมิน
- ประเมินประสิทธิภาพโดยเปรียบเทียบก่อนและหลังใช้งานระบบ
- สรุปผลคะแนนและแสดงความแตกต่างของผลการประเมิน
- ประเมินความพึงพอใจ พร้อมเขียนข้อเสนอแนะเพิ่มเติมs

## เทคโนโลยีที่ใช้

- **HTML** — โครงสร้างหน้าเว็บ
- **CSS** — รูปแบบและการจัดหน้าตาเว็บไซต์
- **JavaScript** — การทำงานของแบบประเมินและการแสดงผล

## วิธีเปิดใช้งาน

1. ดาวน์โหลดหรือ Clone โปรเจกต์
2. เปิดโฟลเดอร์ `evaluator`
3. เปิดไฟล์ `frontend/user/index.html` ผ่านเว็บเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code
4. เลือกหมวดหมู่และระบบ IT ที่ต้องการประเมิน แล้วทำตามขั้นตอนบนเว็บไซต์

## โครงสร้างโปรเจกต์

```text
evaluator/
├── frontend/
│   ├── user/          # หน้าสำหรับผู้ทำแบบประเมิน
│   ├── admin/         # หน้าสำหรับผู้ดูแลระบบ
│   └── assets/        # CSS, JavaScript และรูปภาพ
├── backend/           # ส่วนการทำงานฝั่งเซิร์ฟเวอร์
├── database/          # ไฟล์เกี่ยวกับฐานข้อมูล
├── infomation.md      # เอกสารอธิบายโปรเจกต์
├── requirements.md    # ข้อกำหนดของระบบ
└── README.md          # คู่มือแนะนำโปรเจกต์
```

## หมายเหตุ

โปรเจกต์อยู่ระหว่างการพัฒนา ส่วนการเชื่อมต่อฐานข้อมูลและการบันทึกข้อมูลถาวรควรตรวจสอบเพิ่มเติมก่อนนำไปใช้งานจริง
