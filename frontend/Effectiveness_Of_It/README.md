# Effectiveness of IT

พื้นที่สำหรับพัฒนาระบบประเมินประสิทธิผลของระบบ IT

```text
frontend/Effectiveness_Of_It/
└── main/      # หน้าเว็บและทรัพยากรฝั่งผู้ใช้
```

โครงการนี้ยังไม่มีข้อกำหนดเชิงฟังก์ชันหรือโค้ดเริ่มต้น จึงยังไม่มีคำสั่งรันหรือชุดทดสอบ บริการหลังบ้านในอนาคตให้วางใน `backend/` ที่รากของรีโพซิทอรี
